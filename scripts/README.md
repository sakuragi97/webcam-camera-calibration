# Scripts

Run from the project root.

| Script | Purpose |
|---|---|
| `capture.py` | live preview with board detection and a coverage grid; SPACE saves a full-resolution PNG |
| `undistort_live.py` | original and undistorted video side by side, with fps (maps precomputed once, `remap` per frame) |
| `measure.py` | click points on a photo, get distances in mm on the board plane |
